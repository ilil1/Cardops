# 시연용 합성 A/B 데이터

## 목적

현재 `BankChurners.csv`는 고객별 단일 시점 데이터이므로 실제 전후 변화나 캠페인 대조군 성과를 확인하기 어렵습니다. 로컬 시연 환경에서는 `seed_demo_campaign` 스크립트로 합성 시계열과 캠페인 성과를 생성할 수 있습니다.

합성 데이터에는 다음이 포함됩니다.

- 2026-05-01, 2026-06-01, 2026-07-01 세 시점의 고객 특성 스냅샷
- 세 시점에 대응하는 합성 분석 배치와 고객 분석 결과
- 고위험 리텐션·중위험 재활성화·저위험 업셀링 `[DEMO]` 캠페인
- 캠페인별 대상군·대조군 무작위 배정
- 전환·유지·매출·비용 결과
- 캠페인 이벤트 이력과 A/B 성과 집계 원천 데이터

모든 대상에는 실제 고객 접촉 결과가 아니라는 메모가 저장됩니다. 시연용 데이터는 실제 성과 판단이나 고객 의사결정에 사용하면 안 됩니다.

## 실행

Docker 환경이 실행 중이고 `.env`가 로컬 개발 설정인 상태에서 실행합니다.

```bash
docker compose exec backend python -m backend.scripts.seed_demo_campaign
```

기본값은 캠페인별 180명입니다. 빠른 UI 확인이 필요하면 대상 수를 줄일 수 있습니다.

```bash
docker compose exec backend python -m backend.scripts.seed_demo_campaign --limit-per-campaign 60
```

동일한 `[DEMO]` 캠페인이 이미 있으면 중복 생성하지 않고 종료합니다. 운영 환경이나 원격 DB에서는 실행이 차단됩니다.

## 확인 방법

1. `test_admin` 또는 `test_marketing`으로 로그인합니다.
2. 캠페인 관리 화면으로 이동합니다.
3. `[DEMO]` 캠페인을 선택합니다.
4. 캠페인 대상에서 대상군·대조군을 확인합니다.
5. 캠페인 성과 카드에서 대상군·대조군 전환율, 유지율, 증분효과, ROI를 확인합니다.

시연 데이터의 분석 이력은 고객 상세에서 확인할 수 있지만, 현재 최신 기준일인 2026-08-01의 실제 분석 결과를 덮어쓰지 않도록 합성 스냅샷은 2026-07-01 이전 시점으로 저장됩니다.
