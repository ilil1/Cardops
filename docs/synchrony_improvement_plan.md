# Synchrony 분류 모델 추가 개선 계획

## 목적과 성공 기준

2026-09-25에 아래 비교를 실행하기 전에 작성한 계획이다. 대상은 **기록된 카드 해지를 30일·60일 앞에서 분류하는 모델**이다. 회귀·군집·화면 개편은 이번 실험 범위가 아니다.

- 업무 기준: 매달 고객의 10%를 검토할 때 실제 기간 내 해지 고객을 얼마나 찾는지(Recall@10%)를 높인다.
- 후보 선택의 주지표를 이번에는 월별 Recall@10%의 평균으로 명시한다. 앞선 실험의 AP 기준과 다르며, 지표를 바꾼 결과 자체를 성능 개선으로 주장하지 않는다. AP와 ROC AUC도 함께 공개한다.
- 기존 `previous_core6`와 보유기간 중심 `tenure_control`을 같은 조건에서 다시 비교한다.
- 새 후보의 개발 통과 조건: **두 비교 모델 각각보다 평균 포착률 +2%p 이상, 6개월 중 4개월 이상 개선, 어느 달도 -2%p보다 크게 하락하지 않음**. 수치는 이번 실험의 실무적 판단 기준이며 통계적으로 도출된 값이 아니다.
- 통과 후보 중 평균 포착률이 가장 높은 후보를 선택한다. 없으면 기존 두 비교 모델 중 개발 평균이 높은 모델을 유지한다. 동률은 선언 순서로 결정한다.
- 후기 재검증에서 개선을 주장하려면 비교 모델 대비 개선 방향과 고객 단위 bootstrap 95% 구간을 확인한다. 통과 여부와 관계없이 개발 우승 후보 1개의 후기 결과는 진단용으로 공개하되, 그 결과로 후보를 다시 선택하지 않는다.

## 1. 진단

2025년 기준월만으로 거래 관측량, 보유기간별 위험, 달력 시기 변화, 같은 해지 사건의 반복 정답을 점검했다. 상세: [개발 자료 진단](synchrony_training_diagnostics.md).

- 카드 구매 기록이 0~1행인 고객-월이 61.65%다. 구매 간격을 관측할 수 없는 경우가 많다.
- 보유기간과 시기에 따라 해지율이 달라진다. 단순히 거래 감소에 단조 제약을 걸 근거는 약하다.
- 월말 60일 정답은 동일한 실제 해지 사건을 여러 번 포함하므로 행 단위 독립 신뢰구간을 사용하지 않는다.

## 2. 고정된 실험 후보

기존 비교 모델 2개와 아래 신규 후보 6개를 비교한다. 결과를 보고 후보나 가중치를 추가하지 않는다.

| 후보 | 검증하려는 가설 | 고정 설정 |
|---|---|---|
| `duration_hazard` | 관측 시작 이전부터 보유한 카드와 아직 해지하지 않은 카드를 위험집단 계산에 반영하면 개선되는가 | 일별 보유기간 위험, 평활폭 45일, 달력시간 반감기 180일, 사전 관측량 500 |
| `tenure_calendar_lr` | 보유기간에 따른 위험 모양이 시기에 따라 달라지는가 | 고정 보유기간 절점과 달력시간 상호작용, LR C=0.03, 최근 6개월 |
| `behavior_lr` | 다른 결제수단으로의 이동과 최근 구매일의 결제 비중이 정보를 더하는가 | 기존 핵심 특징 + 고정된 새 행동 특징 18개, LR C=0.03, 최근 6개월 |
| `behavior_cat` | 같은 행동 특징의 비선형 관계가 중요한가 | CatBoost 깊이 4, 300회, 학습률 0.04, L2=30, 최근 6개월 |
| `hazard_behavior_blend` | 보유기간 위험과 행동 모델이 서로 보완하는가 | `duration_hazard`와 `behavior_cat`의 순위 50:50 |
| `tenure_behavior_blend` | 보유기간-시간 모델과 행동 모델이 서로 보완하는가 | `tenure_calendar_lr`와 `behavior_lr`의 순위 50:50 |

순위 결합은 해당 기준일의 전체 대상 고객 안에서 계산한다. 개별 고객의 보정된 해지 확률로 해석하지 않는다. 결합 비율을 학습하지 않으므로 별도 정답을 이용한 스태킹은 하지 않는다.

## 3. 데이터 분리와 동결

- 개발 기준일: **2025-07-31, 08-31, 09-30, 10-31, 11-30, 12-31**.
- 각 개발 기준일 이전에 정답 관측까지 끝난 행만 학습한다. 변환·표준화도 학습 행에서만 적합한다.
- 해지 위험집단 모델은 각 적합일까지만 관측하고 이후 해지일을 사용하지 않는다. 관측 시작은 2024-08-01이다. 관측 시작 이전 보유기간은 진입 시점으로 처리한다.
- 최종 모델 동결: **2026-03-30**. 행 분류기의 최신 학습 기준월은 30일 모델 2026-02-28, 60일 모델 2025-12-31이다.
- 재검증 기준일: 30일 모델 2026년 3~6월 말, 60일 모델 3~5월 말. 모델을 저장하고 다시 로드한 뒤 예측만 수행한다.
- 동일 고객의 과거와 미래 등장은 허용한다. 같은 `(고객, 기준일)`의 학습·평가 중복은 금지한다.
- 모든 모델의 동점은 고객 ID의 고정 해시로 동일하게 처리한다. ID는 모델 입력이 아니다.
- **후기 기간은 이전에 여러 차례 확인한 자료다. 새로운 독립 테스트가 아니며, 이번 결과는 재사용한 기간의 시간순 재검증이다.**

## 4. 검증 및 보고

1. 새 특징이 미래 거래·미래 해지일·최종 고객 속성 변경에 영향받지 않는지 테스트한다.
2. 위험집단의 일수와 해지 수를 작은 수작업 예제로 대조하고, 미래 해지 정보가 적합에 들어가지 않는지 확인한다.
3. 개발 결과·선택 사유를 파일에 저장한 뒤 후기 예측을 시작한다.
4. 같은 고객의 반복월을 묶는 bootstrap으로 차이의 불확실성을 계산한다.
5. 월별 포착률뿐 아니라 서로 다른 해지 고객 수와 최소 14일 전에 발견한 고객 수도 공개한다.
6. 모델·예측·실험 정의·코드 해시와 보고서를 남긴다. 통과하지 않은 실험을 배포 모델로 교체하지 않는다.

## 중단 및 다음 단계

이 후보 집합의 평가가 끝나면 같은 후기 자료를 보며 추가 탐색하지 않는다. 실패해도 데이터의 성능 상한이라고 결론 내리지 않는다. 추가 개선은 새로운 관측 기간 확보, 기존 고객 속성의 과거 변경 이력 확보, 더 촘촘한 거래 기록 등 관측 근거를 늘리는 방향으로 계획한다.

원본에는 수집 시각과 데이터 생성 경위가 명확하지 않다. 기록 시각에 바로 사용 가능했다고 가정하며, 제휴몰 밖의 거래는 관측하지 못한다. 카드 해지가 모두 사전 개입으로 막을 수 있는 이탈이라는 뜻은 아니다.

관측 시작·중도 절단 개념 참고: [lifelines의 entry와 event_observed 설명](https://lifelines.readthedocs.io/en/latest/fitters/univariate/KaplanMeierFitter.html). 이번 위험집단 모델은 별도의 평활된 일별 위험 추정 구현이며 Kaplan–Meier와 동일한 추정량이라고 주장하지 않는다.
